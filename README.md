## Getting Started

### Prerequisites

- Java JDK 8 or higher (`java -version` to check)
- Eclipse IDE (or any Java IDE)

### Installation

1. Clone the repository:
   git clone https://github.com/bhargavasai-creator/animalbreed.git

2. Open Eclipse and import the project:
   - File → Import → General → Existing Projects into Workspace
   - Select the cloned animalbreed folder
   - Click Finish

3. Build and run:
   - Right-click the project → Run As → Java Application
   - Select the main class
